# SLTPIF (Scrcpy Layer That Pipes Into File)
SLTPIF is a project aiming on making recording scrcpy (pronounced **scr**een **c**o**py**) easier!

## How to set-up SLTPIF?
To set this up, just download the 7z file from the releases page (note you need [7-Zip](https://www.7-zip.org) to extract the file), extract it, and run the file named "SLTPIF" (or SLTPIF.bat if you have file extensions on)!

## How do I get the file?
Just close the scrcpy window after you're finished. FFmpeg should start encoding.
